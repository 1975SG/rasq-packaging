## Conventions

The words **shall**, **should**, and **may** indicate a requirement, a
recommendation, and permission, respectively. `NOTE` provides information.
`CAUTION` identifies a condition that can cause loss, exposure, or unexpected
execution.

Paths are relative to the project root unless stated otherwise. Commands are
literal except for values enclosed in angle brackets.

This manual describes observed product behavior. It is not an IEEE, IEC, CE,
or ISO certification.
